# Gemini 젬(Gem)으로 자소서 컨설팅 봇 운영하기

강사 비용 0원 · 배포는 링크 복사 · 학생은 자기 구글 계정으로 사용 (사용량도 학생 계정에서 차감)

## 1. 젬 만들기 (강사, 1회)
1. https://gemini.google.com 접속 → 왼쪽 메뉴 **젬 탐색(Explore Gems)** → **새 젬(New Gem)**
2. 이름: `맞춤형 자소서 컨설팅`
3. **안내(Instructions)** 칸에 `젬_지침.md`의 내용 **전체**를 붙여넣기
4. 오른쪽 미리보기 창에 `시작`이라고 입력해 동작 확인 → **저장**

## 2. 학생에게 공유 (수업마다)
1. 젬 목록에서 해당 젬 옆 **공유(Share)** → 일반 액세스를 **링크가 있는 모든 사용자**로 변경 → **링크 복사**
2. 링크를 단톡방·LMS에 게시
3. 학생 안내 문구 예시:
   > 링크를 열고 구글 계정으로 로그인한 뒤 채팅창에 **"시작"**이라고 입력하세요.

## 3. 결과 저장 (학생)
- 답변 아래 **복사** 아이콘 → 구글 폼에 붙여넣기
- 답변 아래 **공유·내보내기** 메뉴에서 **Google Docs로 내보내기**
- 대화는 Gemini **최근 대화 목록**에 자동 저장되어 나중에 다시 열 수 있음

## 기존 챗봇에서 바꾼 점 (오류 줄이기)
| 기존 | 변경 | 이유 |
|---|---|---|
| "처음 접속하면 인사말 출력" | "첫 메시지가 무엇이든 시작 인사로 답함" + 학생에게 "시작" 입력 안내 | 젬은 사용자가 먼저 말하기 전에는 대답할 수 없음 |
| 비밀번호 4자리 확인 | 삭제 | 젬 공유 링크가 접근을 제한함. AI가 비밀번호를 확인하면 쉽게 뚫리거나 오히려 진행이 막힘 |
| 단계 기억은 AI에 맡김 | 매 답변 첫 줄에 `📍 문항 N/4 · M단계` 표시 | AI가 스스로 위치를 적으면서 단계를 건너뛰거나 문항 수를 잊는 일이 줄어듦 |
| 규칙이 여러 곳에 흩어짐 | "최우선 규칙" 5개로 맨 위에 모음 | 중요한 규칙을 먼저 읽게 함 |
